# AI Tool Usage Record

This file records the use of AI tools during the development of this project. It includes which tools were used, how they were used, interesting observations, and overall reflections.

---

## Tools Used

- **ChatGPT / GitHub Copilot** – used for code suggestions, refactoring, and bug fixes.

---

## Tasks Assisted

AI was used in the following tasks:
- Checking whether test cases covered required scenarios and suggesting additional test cases or edge cases.
- Generating clearer and more consistent JavaDocs comments, while adding specific details manually where AI output was incomplete.
- Assisting with unfamiliar syntax for FXML, saving time on writing boilerplate code

---

## Observations

- AI tools saved time on repetitive or formulaic tasks and worked better with better descriptions and prompts.
- It is still necessary to vet and refine AI-generated documentation to ensure correctness and completeness.
- For JavaDocs and other descriptive comments, AI may miss finer details, requiring manual additions.
- AI can sometimes generate syntax or logic that does not fit the current project context, so careful verification is required.

---

## Reflections

- Overall, AI tools were valuable for speeding up development, especially for repetitive tasks or when learning new FXML syntax.
- Using AI effectively requires understanding its suggestions, prompting it clearly, and cross-checking outputs to avoid errors or “hallucinations.”
